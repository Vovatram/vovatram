* **Языки программирования:** Python, JavaScript

* **Фреймворки и библиотеки:** React, Node.js, FastAPI, SQLAlchemy, React Three Fiber, Tailwind CSS

* **Базы данных и инструменты:** PostgreSQL (включая асинхронный psycopg3), Git, QGIS

* **Специализация:** Анализ данных с микроволновых датчиков, обработка видеопотоков, разработка интерфейсов для диспетчеров ИТС, симуляция дорожного движения и светофорного регулирования

*Пул проектов · Февраль — Май 2026*

* **Разработка платформы для детекции транспортных инцидентов:** Создание ПО для отображения камер и происшествий на интерактивной карте, разработка рабочего места диспетчера.

* **Интеграция каналов связи:** Настройка нотификаций о происшествиях через электронную почту и Telegram.

*Практика · 1–13 Сентября 2026*

### 🚀 Ключевые проекты

1. **Автономная система ведения поездов:**

   * Совместный проект по разработке полностью автономной системы управления поездами на модельной железной дороге.

   * Реализация цифровой карты, трекинг местоположения поездов в реальном времени, контроль отклонений от расписания и алгоритмы антиблокировки для предотвращения тупиковых ситуаций при разъезде составов.

   * Разработка физических светофоров с контролем проезда и создание специализированных модулей ведения поездов для подстройки и удержания постоянной скорости.

2. **Accident-Panel-Detector:**

   * Веб-платформа для мониторинга транспортных инцидентов и диспетчеризации опасных ситуаций.

   * Интерактивная карта с привязкой камер, поддержкой интерфейса управления дронами аэромониторинга инфраструктуры и оперативным уведомлением диспетчеров (Telegram, Email).

   * Аналитика видеопотоков в реальном времени: детекция ДТП, стоянки в запрещённых местах, выезда на встречную полосу и нарушений ПДД пешеходами.

3. **SmartTrafficLight:**

   * 3D-визуализация и моделирование пешеходного перехода и работы ИТС-оборудования (React 19 + Three.js + FastAPI + PostgreSQL).

   * Настройка выделенных полос (трамвай, автобус, вело), остановок, датчиков (камеры, микроволновые датчики, индукционные петли, I2V) и адаптивного светофорного регулирования с функцией исторического Replay.
